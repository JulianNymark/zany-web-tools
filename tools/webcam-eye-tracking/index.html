On-device · nothing is uploaded

Look where you look

Gaze estimation from an ordinary webcam, running in the browser. Calibrate to nine points, then pop a deterministic grid of bubbles with your eyes — same layout and sizes every run, so you can compare attempts or trackers.

Idle. The model is vendored locally and loads only when you press start.

Other ways to eye-track the browser

This page runs MediaPipe Face Landmarker. The field has a few alternatives that trade accuracy, maintenance and licence differently. Expand an entry for the detail; star counts are pulled live from GitHub.

How it works — and what it can’t know

The pipeline

  • MediaPipe Face Landmarker returns 478 face landmarks per frame, including 8 iris points. It runs on-device (GPU, falling back to CPU) via a WebAssembly bundle.
  • From each frame we build a small feature vector: horizontal/vertical iris ratios per eye, head yaw/pitch/roll, face scale, and the combined iris offset.
  • Nine calibration points gather samples; a ridge regression (fit in-page, not a neural net) maps features to screen coordinates.
  • Predictions are smoothed and drawn as a gaze dot with a short trail. A bubble pops once your gaze dwells inside it long enough.

The repeatable test

Bubbles are laid out on a fixed grid. Positions come from the viewport and the grid size; bubble sizes increase in a fixed order from the smallest to the largest. No randomness — a run with the same window size and grid setting is identical every time. The HUD reports targets left, elapsed time, hits and the calibration error in pixels.

Privacy

Video never leaves the machine: the model is vendored in assets/vendor/mediapipe/ and inference happens in your browser. The camera stream is stopped when you press stop or leave the page. The only network request is the optional live star count from the GitHub API.

Limits & requirements

  • Needs a secure context: it works over HTTPS or localhost. Opening the file directly (file://) blocks the camera and the WebAssembly module.
  • You need to serve the folder — the site does this on GitHub Pages; locally run python3 -m http.server from the repo root.
  • Sit roughly 50–70 cm from the screen, face lit from the front, and keep your head fairly still.
  • Accuracy depends on your webcam, glasses and lighting. Expect centimetres, not millimetres.

Tech used

  • MediaPipe Face Landmarker (@mediapipe/tasks-vision 1.0.1, Apache-2.0)
  • Designsystemet for UI and tokens
  • Calibration and feature extraction are plain JavaScript, ported from a standalone demo
